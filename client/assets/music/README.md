# Musiques du jeu

Dépose ici les musiques publiques du jeu.

Formats pris en charge :
- `.mp3`
- `.ogg`
- `.wav`

Aucune playlist n'est nécessaire : au lancement du serveur, le jeu liste automatiquement tous les fichiers audio présents dans ce dossier et les joue aléatoirement avec des pauses entre les morceaux.

Les fichiers placés ici sont servis à tous les joueurs, pas seulement à un utilisateur local.

Conseil : privilégier `.ogg` ou `.mp3` pour le web. Les `.wav` fonctionnent mais sont souvent très lourds.
